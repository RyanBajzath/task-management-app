# Task Management App

A React Native task management app built with Expo.

## Features

- Create tasks
- View task list and details
- Edit tasks
- Delete tasks with confirmation
- Search tasks by title
- Filter by status
- Move tasks from `todo` to `doing` to `done`
- Select due dates with a date picker
- Save tasks locally with AsyncStorage

## Technologies

- Expo
- React Native
- TypeScript
- NativeWind
- Expo Router
- React Context
- AsyncStorage

## Setup

```bash
git clone https://github.com/RyanBajzath/task-management-app.git
cd task-management-app
npm install
npx expo start
```

## Task Fields

Each task includes:

- Title
- Category
- Description
- Status
- Due date
