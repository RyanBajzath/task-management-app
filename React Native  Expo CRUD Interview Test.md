# React Native / Expo CRUD Interview Test

## Test Duration

5 days

# Test Objective

Please use the following technologies to build a “Task Management System”.

The following three technologies are required:

- Expo
- React Native
- NativeWind / Tailwind

Better to have:
Gluestack-ui : https://gluestack.io

Other technologies may be chosen at your discretion:

- AsyncStorage
- SQLite
- Mock API
- Zustand / Context
- Expo Router / React Navigation

---

# Feature Requirements

## 1. Create Task

Users can create a new task.

Fields include:

- title
- category
- description
- status
- dueDate

---

## 2. Read Tasks

Must include:

- Task list page
- Task detail page

The list should display at least:

- title
- category
- status
- dueDate

---

## 3. Update Task

Users can update:

- title
- category
- description
- status
- dueDate

---

## 4. Delete Task

Users can delete a task.

A confirmation prompt is required before deletion.

---

# Additional Feature Requirements

## Filtering

Tasks can be filtered by status:

- All
- Todo
- Doing
- Done

---

## Search

Tasks can be searched by task title.

---

## Status Transition

Task status should be switchable in the following order:

todo → doing → done
---

## Data Persistence

Data must not exist only in memory.
Please use at least one of the following:

- AsyncStorage
- SQLite
